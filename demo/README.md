# A2T 掩蔽声生成演示（Demo）

明天展示用的单文件网页 demo。**纯浏览器本地运行，无需联网、无需安装任何东西。**

## 怎么打开

直接双击 `masking_demo.html`（推荐 Chrome / Edge）。

- 想录麦克风的话，`file://` 打开方式浏览器不允许录音，可以改用本地服务器：
  `python -m http.server 8000`（在本目录运行），然后访问 `http://localhost:8000/masking_demo.html`。
  不用麦克风也不影响演示：上传文件和内置示例都可以。

## 演示流程（约 2 分钟）

1. 点「🎧 使用内置示例」载入合成鼾声（或「📂 上传音频文件」换成真实录音）。
2. 风格选「🌧️ 稳定雨声」（也可选连续水流 / 海浪 / 风声 / 粉红 / 棕噪声）。
3. 点「✦ 生成掩蔽声」。
4. 按「▶ 目标声 → ▶ 掩蔽声 → ▶ 混合播放」顺序试听；混合播放时会显示共同衰减值。
5. 讲频带覆盖图：橙色 = 目标声各频带电平，蓝/绿线 = 掩蔽声；绿色 = 该频带掩蔽声不低于目标声。
6. 可拖动 ΔL（−6 ~ +15 dB）重新生成，演示"电平预算"；「🎲 换一种随机纹理」演示同目标不同纹理（种子受控可复现）。
7. 「⬇ 下载 WAV」可导出掩蔽声。

## 实现口径（给老师讲清楚）

- 这是**无训练模型的概念验证**：真实的掩蔽声生成模型（BEATs 条件 + 潜空间扩散 + DAC）
  在研究计划中尚未实现。本页的"生成"是程序化合成：
  各风格底噪（雨滴瞬态 / 水流气泡 / 浪涌 / 风的带通漂移 / 彩色噪声基线）
  经 STFT 域频带覆盖整形（把掩蔽声各频带电平抬到 目标电平 + ΔL），再做 RMS 电平匹配与软限幅。
- 频带覆盖图是**代理示意**：频带覆盖是必要条件而非充分条件，不能等同于人的干扰感受。
- 未使用任何云端服务；音频不出本机。
- 版本：demo-v0.1，随机种子固定可复现（20261101 + 纹理序号）。

## 已知限制

- 只处理输入的前 30 秒。
- 掩蔽声时长与目标声一致（演示场景），不是长时循环播放研究中的交叉淡化拼接。
- 海浪 / 风声为风格预览，不属于第一版类别。
