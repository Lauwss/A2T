听觉阈值听测

检验掩蔽阈值模型预测的边界和你耳朵听到的边界是否一致。全程约 5–8 分钟。

测试流程

  • 每个题目播放一段噪声，噪声里可能藏着一个纯音。
  • 你判断能不能听到这个纯音：听到了 / 不确定 / 没听到。
  • 共 20 题（4 个频率 × 5 个电平）。顺序已随机打乱。
  • 做完后页面直接给出结果：你的真实阈值和模型预测差多少 dB。

听测条件

  • 安静房间，关闭风扇和空调。
  • 用头戴耳机，不要用音箱。
  • 整个测试音量保持不变。中途改音量会让数据失效。
  • 判断标准：这个纯音「总体上能不能察觉」。忽隐忽现算能察觉。
  • 实验前不要打开 answers.json（答案表）。

第 0 步：校准音量

先听纯噪声（没有纯音）。把系统音量调到：噪声清晰可闻，长时间听也不吵的水平。

结果

边界 = 你刚好能听到纯音的电平，相对模型预测阈值（0 dB）的偏移。

怎么解读

  • 边界在 ±3 dB 内：模型校准和你的听感一致。
  • 边界 < 0：你在模型说「听不见」的电平还能听见 → 模型高估掩蔽。
  • 边界 > 0：模型说「听得见」的电平你其实听不见 → 模型低估掩蔽。
  • 四个频率边界整体平移同一个数：多半是播放音量和 92 dB 假设的差，不是模型错。看「频率间离散度」。
  • 边界贴到 ±6 dB 的边：刺激电平范围不够，用 --offsets 扩大范围重测。
