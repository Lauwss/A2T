# 掩蔽阈值模型 MVP：数学建模、实现与验证

> 状态：已实现并通过测试（2026-10-25）。这是**代理指标**：未经过人类听音验证，
> 不能等同于人类干扰感受、专注效果或助眠效果。所有电平均为数字域相对电平；
> 播放声压（92 dB SPL ↔ 0 dBFS）只是模型标定假设，不是真实播放声明。

## 1. 目的与范围

Evaluation 板块的第一版掩蔽阈值模型，回答一个问题：**给定目标声（待掩蔽）与
掩蔽声（环境音），在哪些帧、哪些频带、哪些事件里目标声超过可闻阈值。**

建模基础为项目参考文档《感知音频质量的客观测量方法》（ITU-R BS.1387-2 中文版）
附件2 §2.1 的 FFT 耳模型（式(1)–(26)），加上 NMR 聚合（式(70)–(71)）。
选择 FFT 模型而非滤波器组模型：结构简单、复杂度低、可解释、无滤波器组设计参数。

## 2. 信号约定

- 输入为等长单声道信号：`target`（目标声）、`masker`（掩蔽声）、`mixture`
  （评估混音，仅用于噪声模式路径）。采样率需 ≥ 36 kHz（验证与默认均为 48 kHz）。
- 全程数字域。模型内部用「假设播放声压级」标定：0 dBFS 满幅正弦 ≙ 92 dB SPL
  （文档对未知播放级别的建议值）。对外报告一律为 dBFS 或相对电平。
- 频带：Schroeder 巴克标度（式(10)），80 Hz–18 kHz，0.25 巴克分辨率 → 109 带，
  与文档表6逐值一致（见测试）；末带上缘按表6封顶 18 kHz。

## 3. 数学建模（对应参考文档公式）

| 步骤 | 公式 | 说明 |
| --- | --- | --- |
| 分帧 | 式(1) | 2048 点帧、1024 点跳（48 kHz 下 21.3 ms 帧距） |
| 加窗 | 式(2)–(3) | 缩放 Hann：`0.5·√(8/3)·(1−cos(2πk/(N−1)))` |
| DFT | 式(4) | 1/N 归一化，取单侧谱 |
| 电平标定 | 式(5)–(6) | `fac = Norm·10^(Lp/20)`，`Lp=92`；`Norm` 取 1019.5 Hz 满幅正弦 10 帧谱系数最大绝对值的**倒数**，使标定正弦恰好映射到 92 dB（见 §4.1） |
| 外中耳加权 | 式(7)–(9) | `W(f)` 幅度加权；f=0 处取 −200 dB 抑制直流 |
| 频带能量 | 式(11)+伪代码 | bin 能量按频带边界的重叠比例累加（与附录伪代码四种情形等价），下限 1e−12 |
| 内部噪声 | 式(13)–(14) | `P_Thres = 10^(0.4·0.364·fc_kHz^−0.8)` 加进音高模式 |
| 频率扩展 | 式(15)–(20) | 双边指数：下斜率 27 dB/巴克；上斜率 `−24−230/fc+0.2L` 并截断于 −4 dB/巴克（沿用式(33)滤波器组版本的截断）；逐源能量归一（式(18)分母）；p=0.4 幂和聚合（式(17)）；`Norm_SP`（式(19)–(20)，L=0 斜率）固定归一 |
| 时域扩展 | 式(21)–(24) | 逐带一阶低通 + 取最大：τ = 8 ms + (100/fc)·22 ms；帧距取 `hop/fs`（48 kHz/1024 时与式(24)一致） |
| 掩蔽阈值 | 式(25)–(26) | `M = max(E/10^((m[k]+c)/10), E_Thres[k])`；m[k] = 3.0（≤12 巴克），否则 0.25·k·res；c = 8.3 dB 标定常数（见 §4.2）；`E_Thres[k] = 10^(0.364·(fc/1kHz)^−0.8)`（式(60)）作绝对听阈地板 |

输出（`MaskingReport`，帧级/频带级/事件级全部保留）：

- `margins_target_db[k,n] = 10·log10(Pe_target[k,n]/M[k,n])`：主判定路径；
  正值 = 该带该帧目标声超过阈值。
- `margins_noise_db[k,n]`：PEAQ 噪声模式（式(62)，`||Fe_mask|−|Fe_mixture||`）
  对 M 的比值，聚合成 NMR（式(70) 本地、式(71) 总量）。
- 活动门限：`Pe_target[k,n] > P_Thres[k]`（目标带能量高于内部噪声地板才算
  "有目标"），避免把静音判为可闻。
- 帧级：任一活动带 margin>0 → 可闻；否则该帧被完全掩蔽。
  `masked_frame_ratio` = 被掩蔽帧 / 活动帧。
- 事件级：连续活动帧合并为事件，输出每事件掩蔽帧比与最小裕量。
- 四条件对照（`compare_conditions`）：correct / mismatched（时移半长）/
  unconditional（零掩蔽）/ traditional_pink（与候选掩蔽声 RMS 对齐的粉红噪声），
  满足项目协议要求的对照条件。

## 4. 对参考文档的实现决策与偏差

### 4.1 式(5) 的 Norm 取倒数

按字面把 Norm 实现为标定正弦的谱峰最大值（≈0.345），满幅正弦只映射到约 73 dB，
与式(5)–(6)"按假设播放声压级缩放"的目的矛盾（差 ~18 dB）。实现取其倒数
（≈2.89），标定正弦精确映射到 92 dB，且由此推出的静音听阈与式(60)锚点一致
（见 §5 E1），验证了该读法。

### 4.2 式(26) 的掩蔽偏移：排版对调 + 标定常数

译文为 `M = E/10^(10/m[k])`，即低于激励 33.3 dB。这会同时违反同一文档的
两个锚点：§3.5 明确"噪声掩蔽下，被掩蔽声比掩蔽声低 5 dB 左右即不可闻"
（33 dB 差 ~28 dB），且静音听阈将落到 −33 dB SPL 等效（真实听阈 ≈ +3 dB）。
据此判定为分子分母排版对调，实现为 `M = E/10^(m[k]/10)`（偏移 = m[k] dB，
3.0 → 6.75 dB 随频率上升）。

在此基础上实测宽带掩蔽偏移为 +3.1 dB（相对 −5 dB 锚点还差 8.1 dB，来自
p=0.4 聚合对粉红噪声这类缓坡谱的轻度压低），故引入**单一全局标定常数**
`masking_offset_calibration_db = 8.3`，只作用于激励推导的掩蔽阈值。
它不是自由拟合：由 §3.5 锚点唯一确定，并在独立锚点（静音听阈）上交叉验证。

### 4.3 绝对听阈地板

标定常数会连带把静音听阈压低 8.3 dB。心理声学上"安静中检测"与"掩蔽下检测"
是不同机制，文档也分别处理（式(13)/(60) 内部噪声与响度阈、式(26) 掩蔽）。
故最终阈值取 `max(激励推导阈值, 式(60) 响度模型阈值)`：掩蔽永远不会把
可闻阈抬到高于安静听阈，也不会低于它。

### 4.4 其他

- 上斜率截断 −4 dB/巴克：取自式(33)（滤波器组版本），防止极高电平时上斜率
  失去衰减。48 kHz 满幅以下不触发。
- 旧 `MaskingEvaluator`（帧级能量比基线）保留未动，作为最简对照。

## 5. 验证方法与结果

验证采用**双分法探针实验**：固定掩蔽声，二分搜索探针音幅度使模型裕量过零，
与参考文档/文献锚点比较。全部信号合成、种子固定（20261025），可用
`scripts/validate_masking_threshold.py` 复现，数值存于
`artifacts/masking_mvp/validation_results.json`。以下为 48 kHz、1.5 s、
掩蔽声 RMS 0.1（−20 dBFS）下的实测结果。

**E1 静音听阈（无掩蔽声）vs 式(60) 锚点**

| 频率 | 模型（SPL 等效） | 锚点 | 偏差 |
| --- | --- | --- | --- |
| 500 Hz | +5.3 dB | +0.6 dB | +4.7 dB |
| 1 kHz | +1.2 dB | +0.4 dB | +0.8 dB |
| 2 kHz | +0.1 dB | +0.2 dB | −0.1 dB |
| 4 kHz | 0.0 dB | +0.1 dB | −0.1 dB |
| 8 kHz | −2.5 dB | +0.1 dB | −2.6 dB |

在 ±5 dB 内，且与真实听阈曲线（1 kHz ≈ +3 dB SPL 量级）走向一致。

**E2 宽带（粉红）噪声掩蔽音调的偏移 vs §3.5 锚点（−5 dB）**

| 频率 | 偏移 | 偏差 |
| --- | --- | --- |
| 500 Hz | −5.09 dB | −0.09 dB |
| 1 kHz | −5.17 dB | −0.17 dB |
| 2 kHz | −5.36 dB | −0.36 dB |
| 4 kHz | −4.75 dB | +0.25 dB |

标定后 |偏差| ≤ 0.36 dB（按构造校准，交叉验证见 E1）。

**E3 窄带（100 Hz）掩蔽偏移**：−14.61 dB（锚点 −5 dB，偏差 −9.6 dB）。
p=0.4 幂和归一化对局部化激励的压低所致。**已记录为局限**：对窄带掩蔽声
模型高估掩蔽 ~10 dB；A2T 的掩蔽声（雨声/水流）为宽带，落在 E2 验证过的区域。

**E4 掩蔽模式衰减斜率**（直接测量 M 的空间衰减，rms 0.316 掩蔽声）：
向上 −8.77 dB/巴克（与式(15)在该电平下的预测 ≈ −7.9 一致）；
向下 +15.41 dB/巴克（核名义值 27，p=0.4 聚合使其变缓，已记录）。
不对称方向正确：掩蔽声频率越高、对更低频的掩蔽衰减越快，即"向上扩展"
延伸更远，符合文献方向。

**E5 前向掩蔽**：掩蔽声结束探针裕量 +16.1 dB → +28.9 dB（+50 ms 后饱和到
静音地板），单调、随式(21)–(24) 时间常数衰减。

**E6 电平线性**：掩蔽声电平 +10 dB → 阈值 +10.7 dB（1.067 dB/dB，接近理想 1.0）。

**测试**：36 项全部通过（`pytest`），其中含表6逐值对照、公式常量回归、
锚点容差断言（E1 ±3 dB、E2 ±3 dB）、单调性/事件划分/四条件确定性等。

## 6. 已知局限与风险

1. **窄带掩蔽声高估掩蔽 ~10 dB**（E3）。缓解：A2T 掩蔽声为宽带；后续若需
   窄带精度，可评估 1 巴克分辨率（NMR 风格）或 tonality 加权。
2. **无 tonality 区分**：文档 §3.5 的"音调掩蔽噪声 (15.5+z) dB"未建模；
   FFT 模型对掩蔽声一律按噪声处理。
3. **无后向掩蔽**：FFT 模型只有前向掩蔽（式(21)–(24)）；滤波器组模型的
   反向掩蔽（式(35)）未实现。
4. **无双耳/空间掩蔽**、无信息掩蔽等认知效应（文档 §3.8）。
5. **p=0.4 聚合**对局部化激励有结构性压低，是 E3 偏差的来源之一。
6. **未做人类听音验证**。模型锚点是文档与文献值，不是本项目的听测数据；
   掩蔽分数只作排序与筛选的代理指标（AGENTS.md 约束）。
7. 播放级别假设（92 dB SPL ↔ 0 dBFS）未校准到任何真实设备。

### 7.1 可调探针测试与盲听导出（2026-11-09 新增）

`scripts/probe_test.py` 用任意掩蔽声跑探针实验，并可导出一组盲听刺激：

```bash
# 粉红噪声掩蔽，四个探针频率
.venv/Scripts/python.exe scripts/probe_test.py

# 窄带掩蔽（复现 E3）
.venv/Scripts/python.exe scripts/probe_test.py --masker narrowband \
    --narrow-center 1000 --narrow-width 100 --freqs 1000

# 用真实 WAV 掩蔽声（按其自身采样率分析，>= 36 kHz）
.venv/Scripts/python.exe scripts/probe_test.py --masker file \
    --masker-file Datasets/rain.wav --freqs 1000,2000 --export artifacts/probe_test
```

`--export DIR` 写出 `masker_only.wav`、每个频点 5 个电平档（阈值 ±6 dB，
标签 A–E 随机分配）、不含电平信息的 `manifest.json` 和答案表
`answers.json`。听测方法：安静房间、头戴耳机、固定音量，按 A–E 顺序
播放，记录纯音首次出现的标签，再对照答案表；校准良好的模型把这条边界
放在 0 dB 档。若五档全部可闻或全部不可闻，说明偏差超过 ±6 dB，可用
`--offsets` 扩大范围（例如 `-18,-12,-6,0,6`）。

数值自检结果：粉红噪声四频点偏移与 E2 完全一致；窄带 1 kHz 偏移
−14.60 dB 与 E3 的 −14.61 dB 一致；静音听阈换算 SPL 与 E1 一致；
导出的 20 个 WAV 实测探针电平与答案表相差 ≤ 0.003 dB。

### 7.2 听测前端（2026-11-13 新增）

`demo/listening_test.html` + `scripts/listening_server.py` 提供图形化
盲听测试：页面加载 `manifest.json`（只含文件名与标签，不含电平），
逐题循环播放刺激并记录 听到了/不确定/没听到，结束后取回 `answers.json`
自动计算每个频率的听测边界（0.5 概率插值），与模型预测（0 dB）比较，
并区分「整体偏移（多为播放音量与 92 dB 假设之差）」与
「频率间离散度大（指向模型频带相关偏差）」。

```bash
.venv/Scripts/python.exe scripts/listening_server.py --dir artifacts/probe_test --open
# 浏览器打开 http://127.0.0.1:8765/ ，按页面指引完成 20 题
# 结果自动保存到 artifacts/listening_test/listening_results_<时间戳>.json
```

解读规则：边界 ≈ 0 dB 为校准一致；边界 < 0 为模型高估掩蔽（模型说
听不见的电平人耳仍能听见）；边界 > 0 为模型低估掩蔽。进度存于
浏览器 localStorage，中途刷新可继续。换掩蔽声后需重新跑
`probe_test.py --export`（manifest 变化会使旧进度失效）。

校准页含**练习音**按钮：页面内合成掩蔽声 + 明显可闻的 1 kHz 纯音
（约高于模型阈值 20 dB），用于验证音频链路并建立听感预期；
练习音听不清即音量或设备问题，应先排除再进入盲听。

**首轮听测记录（2026-11-13）**：粉红噪声掩蔽、档位 −6/0/+6/+3/+6
（见 `artifacts/listening_test/listening_results_20261113_005104.json`），
20/20 回答「没听到」，四频率边界均 ≥ +6 dB 贴上边。每题仅播放一次
（2–4 s），无「不确定」回答（无假阳性）。解读（按可能性排序）：
(1) 理想检测阈值与未训练听者 50% 检测点的差距（文献常规 5–10 dB，
且短时单次播放进一步降低检出率）；(2) 播放音量低于 92 dB 假设——
注意掩蔽限制检测下均匀音量缩放不改变相对边界，只有差距大到约
40 dB 以上（纯音接近真实静音听阈）才会显著推高边界；(3) 模型整体
偏差 ≥ 6 dB（与 E1/E2 锚点矛盾，未排除）。首轮只能给出边界下界。
**第二轮规程**：`probe_test.py --export --offsets=-6,0,6,12,18` 扩大
电平范围，校准页先播练习音确认链路，每题建议循环播放 2–3 个周期
再作答，可用「不确定」作中档回答。

**二轮听测记录（2026-11-13）**：档位 −6/0/+6/+12/+18
（`artifacts/listening_test/listening_results_20261113_010043.json`）。
20 题回答分布：8 no / 7 yes / 5 unsure。修正后的边界（页面 v1 评分
有跨频率标签匹配 bug，显示值错误；用 `scripts/rescore_listening.py`
对原始作答重算，结果存于脚本输出）：500 Hz +9.0 dB、1 kHz +12.0 dB、
2 kHz +6.0 dB、4 kHz +15.0 dB，**平均 +10.5 dB，标准差 3.9 dB**。
解读：(1) 听者 50% 检测点比模型（理想检测器）边界高约 6–15 dB，
量级与"未训练听者比理想阈值钝 5–10 dB + 单次短时播放"的文献预期
相容，模型作为绝对预测器对未训练听者偏乐观约 10 dB，作为排序指标
不受影响的证据仍在积累；(2) 2 kHz 最接近理想（+6），4 kHz 偏差最大
（+15），但单次会话 n=5/频点，频率依赖性尚不能下结论；(3) 两个
−6 dB 档的「不确定」为疑似 lapse，按规则剔除出边界计算；(4) 每题仍
只播放一次（1.4–9.2 s），响应噪声是主要误差源。**评分规则 v2**：
边界 = 最高「没听到」档与最低「听到了」档的中点，「不确定」剔除；
结果 JSON 升级为 version 2（含 boundaries_hz.kind/boundary_dbfs/
offset_db）；answers.json 新增 model_threshold_dbfs 供页面换算偏移。

**三轮听测记录（2026-11-14）**：同二轮刺激
（`artifacts/listening_test/listening_results_20261114_000358.json`，
页面 v2 评分）。作答单调性明显改善：500 Hz **+9.0 dB（与二轮完全
一致，复现）**、4 kHz +9.0 dB（二轮 +15）、2 kHz −3.0 dB（低于模型
预测）、1 kHz 非单调（−6 档答"听到了"而 0/+6 档答"没听到"，疑为
−6 档假阳性或 0/+6 档 lapse；rescore 脚本标记 inverted 并剔出
均值）。有效均值 +5.0 dB（sd 6.9，n=3）。两轮合并估计：模型边界对
未训练听者偏乐观约 **5–10 dB**；500 Hz 两轮完全复现；单频会话间
波动可达 9 dB（2 kHz +6 → −3）。混杂因素：三轮前听者已被告知二轮
结果（期望偏置，协议失误）、页面增益 80%→120%、深夜时段、每题仍
单次播放（played_count 全为 1）。**结论**：yes/no 盲听在单会话下
无法分离标准偏置与灵敏度，继续重复收益递减；采纳 **+10 dB 未训练
听者余量**作为文档化工程校准（评估解读用，不写入模型内），如需
